Privacy Policy — Biggs Pinterest App

Last updated: October 15, 2026

Operator: Biggs (Splitcreek shop)

What this app does

This app is a personal assistant tool built for a single Pinterest account owner (Biggs). It uses the Pinterest API to publish the owner's own product Pins to the owner's own boards. The app is for one account only.

What data it accesses

Through Pinterest's official OAuth login, and only with the account owner's approval, the app accesses:

  • The owner's Pinterest account information (username, profile).
  • The owner's boards (titles and IDs), so Pins can be published to the right board.
  • The owner's Pins, to confirm a published Pin is live.

What it does not do

  • It does not access any other Pinterest user's data.
  • It does not collect, ask for, or store Pinterest passwords.
  • It does not scrape Pinterest content.
  • It does not sell, share, or disclose any data to third parties.

How data is stored

OAuth access and refresh tokens are stored securely in the assistant's credential vault and are used only to call the Pinterest API on the owner's behalf. No Pinterest data is stored outside the owner's own account except short-lived working logs of published Pins (title, board, and Pin URL).

Disconnecting

The owner can revoke access at any time from Pinterest Settings > Security > Apps, or by removing the connection in the assistant. Revoking immediately stops all API access.

Contact

Questions about this policy can be sent through the Pinterest account that owns this app.
